# 自检题正确答案恒为第一项 — bug 修复

**Status**: resolved

## 学到的

学员反馈：「自检生成有问题，正确答案都是第一个」。

排查发现两层根因：
1. **quiz.js 没洗牌**：选项按 `<script type="application/json">` JSON 原顺序渲染，从不打乱。
2. **写课时的系统性偏差**：我每道题都把 `correct: true` 放第一个（图方便，照抄"正确答案写最前"的写作惯性）。抽检第 6/9/11 课，每课 4 道题，`correct: true` 100% 在第一项。

这违反了最初"避免格式泄题"的约定（NOTES.md 课程设计规则里明确写过）。学员点第一个永远对，等于没有自检功能。

## 修复

**方案**：在 quiz.js 运行时洗牌，不回改 13 个课文件的 JSON。
- 在 `assets/quiz.js` 顶部加 Fisher-Yates `shuffle()` 函数。
- 在 `enhance()` 里渲染选项前 `options = shuffle(options.slice())`。
- 每次刷新页面选项顺序都不同，彻底杜绝"背位置"。

**为什么选运行时洗牌而非回改 JSON**：
1. 一处修复全部生效（13 个课文件都受益）。
2. 不用回改大量 JSON（易错）。
3. 每次刷新顺序随机，比静态打乱更强。
4. `opt.correct` 标记跟着选项走，洗牌后正确性不变。

## 教训

- 写自检题时**不要**把正确答案系统性地放某一位置。以后写新课时，刻意随机化 `correct: true` 的位置（即使有运行时洗牌，源文件也该 randomized，双重保险）。
- "避免格式泄题"这条规则要主动验证，不能假设自己遵守了。抽检 `grep -c '"correct": true'` 应该看到分布在多个位置。
- 组件设计（quiz.js）应该内置反作弊机制（洗牌），不依赖内容作者的自律。

## Implications

- ✅ quiz.js 已修复，所有课的自检题现在每次刷新都随机顺序。
- ⚠️ 后续写新课时，`correct: true` 位置要手动随机化（虽然运行时已洗牌，源文件也该规范）。
- ✅ 这是功能性 bug，不是内容错误，不影响已学知识。
