标准、组织与修正案字母汤 —— 802.11 的家谱

主课程里修正案编号零散出现过：11e（QoS）、11n（MIMO）、11r（漫游）、11ax（Wi-Fi 6）……这课把它们整张排进家谱。目标不是背全——是听到/看到一个字母，能立刻有印象"它是哪一代、管哪块、去哪查"。这是把 CWNA 这本工具书用成手册的第一块索引。

支点：标准分三层，三层各说各话

本课支点 / Core Insight

人们嘴里的"Wi-Fi 标准"其实混着三层东西：法规层（谁允许你用哪段频率、多大功率——ITU（国际电信联盟）和各国监管机构）、技术层（IEEE 802.11 修正案——协议怎么写）、认证/营销层（Wi-Fi Alliance（Wi-Fi 联盟）——产品拿到"Wi-Fi 6"标签的认证测试）。

三层经常被混为一谈："Wi-Fi 6 是标准吗？"——11ax 是标准，"Wi-Fi 6"是认证名。分清三层，你才能准确回答"这个特性写在哪份文档里"。

① 谁管什么：四层机构一张图

ITU-R (国际电信联盟无线电通信部门) 划全球/区域频率表 (无线电规则) │ "这段频率给移动/固定/卫星…" ▼ 各国监管机构 FCC(美) / ETSI(欧洲电信标准化协会) / ARIB(日本)… │ 具体法规域: 频段+功率+DFS(动态频率选择)要求 ← 主课第16课 iw reg ▼ IEEE 802.11 工作组 (WG) │ 任务组机制: TGn → 11n, TGax → 11ax, TGbe → 11be │ 字母用完后用双字母: aa, bb, … bf (2010 年起) ▼ Wi-Fi Alliance (WFA, Wi-Fi 联盟) 互操作性认证 + 品牌名 Wi-Fi CERTIFIED 6 / WPA3 / WMM / Passpoint …

顺带一提认证阶梯（书的出版方 CWNP 体系）：CWNA（认证无线网络管理员）是入门级，上面还有 CWSP（安全）、CWAP（分析）、CWDP（设计）、CWNE（专家）——本书就是 CWNA 的官方教材，你现在等于把它的内容体系化地啃完了。

两个"字母陷阱"：802.11F 和 802.11T 不是标准修正案，是"推荐实践"（Recommended Practice，大写字母）：11F（IAPP，接入点间协议）2006 年已被撤销；11T（无线性能预测/测试方法）2008 年左右解散、从未发布。所以它们永远不会出现在整合版里——看到有人把它们列进家谱当标准，你就知道他没翻过原始文件。

③ 整合版（Rollup）：标准文本的"再版"

IEEE 每隔几年把零散修正案卷进一份新的基线文档，避免你要翻十几份 PDF：

802.11-1997 ─ 1999 卷入 a/b ─ 2007 (TGma) 卷入 d/e/g… ─ 2012 卷入 n/u/v/y… ─ 2016 卷入 ac/af/ai… ─ 2020 (TGme) 卷入 ai/ah/aj/ak/aq/ax ← 11ax 的正式文本在这 ─ 2024 卷入 11be 等 ← Wi-Fi 7 的正式文本在这

手册技能：查 11ax/11be 条款，别去找名为"802.11ax"的现行文档——内容已在 802.11-2020 / 802.11-2024 基线里（单行本只有历史意义）。修订任务组叫 REVme/REVme 后继，与 TGme 一脉。

④ 认证层：Wi-Fi 4/5/6/7 的商业名字

营销名对应标准年份一代关键词
Wi-Fi 4802.11n2009MIMO、40MHz
Wi-Fi 5802.11ac2013宽信道、MU-MIMO 下行（Wave2）
Wi-Fi 6 / 6E802.11ax2019/2021OFDMA、高密度；6E = 6GHz 频段扩展，不是新标准版本
Wi-Fi 7802.11be2024320MHz、4096-QAM、MLO

注意两个细节：① 只有 Wi-Fi 4 之后有数字名，11a/b/g 是回头补叫的 Wi-Fi 2/3/1，日常没人用；② WFA（Wi-Fi 联盟）认证的是互操作性（不同厂商设备能不能一起工作），不是协议正确性——所以存在"实现了 11ax 但没去做 Wi-Fi 6 认证"的芯片。WPA（Wi-Fi 保护访问）/WPA2/WPA3 也是 WFA 的认证计划名，协议本体分别是 802.11i 前身/11i/SAE（对等同步认证，主课 10）。

对驱动工程师：家谱的实际用处

对驱动重要 / For Driver Stack
  • 代码注释里的条款号：mac80211/驱动源码注释大量直接引用修正案条款（如 "11w: protected mgmt frames"、"11ax: TWT"）——认识字母汤才能顺藤摸瓜找到标准原文。
  • 能力协商 IE 的出处：每个能力 IE（信息元素）来自哪个修正案，决定了它出现在哪些代设备上（HT IE 只有 11n+ 有）——排查兼容性问题时的第一反应。
  • 查文档路径：特性 → 修正案字母 → 802.11-2020/2024 基线条款号 →（要实现细节时）内核文档/代码。这条链你以后每周都会走。

这课的钉子：三层四层一张家谱

  1. 分层：ITU-R（国际电信联盟无线电通信部门）/各国监管（法规）→ IEEE 802.11 WG（技术）→ WFA（认证营销）；"Wi-Fi 6"是认证名，"11ax"是标准名
  2. 家谱：11a/b/g（速率）→ 11e/i/k/r/v/w（质量/安全/漫游）→ 11n/ac/ax/be（代际吞吐）+ 冷门支线（p/s/u/ad/ay/ah）
  3. 整合版：2007/2012/2016/2020/2024 卷积史——查条款先想"卷进哪版了"
  4. 陷阱：11F/11T 是推荐实践非标准；6E 是频段扩展非新版本

你现在能做的：把家谱表当地图——以后在任何文档/代码里遇到字母，回这课对一眼"哪代、管哪块"。
