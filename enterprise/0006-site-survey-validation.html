勘测与验证 —— 怎么判断"这环境行不行"

企课 5 讲了设计应该长什么样；这课讲怎么测量现实：专业的勘测方法论（书的 Ch14）+ 你用主课第 20 课工具就能做的迷你验证。对你的直接价值：面对"这个环境能不能稳定拉流"的问题，你有一套可复现的测量动作，而不是凭感觉。

支点：先问清楚要什么，再动手测量

本课支点 / Core Insight

勘测的 80% 在动手之前：需求访谈定标准（多少用户、什么应用、语音还是视频、漫游范围），标准决定测什么、目标线画哪（企课 5 的 −67dBm（分贝毫瓦）/SNR（信噪比）25dB 那张表）。没有目标的测量只是收集数据，不是勘测。

① 四种勘测，四个用途

类型怎么做得到什么局限
预测勘测
Predictive		软件建模（Ekahau 等画图纸放虚拟 AP）设计蓝图（AP 位置/功率/信道建议）模型≠现实（建材、干扰未知）
被动勘测
Passive		勘测网卡只听不连，走场记录信号分布信号/SNR 热图、邻居 AP 清单测不到真实吞吐/重传/漫游
主动勘测
Active		客户端真实关联 AP 走场，边走边测实际吞吐/重传率/漫游行为改变环境（自己就是流量）
验证勘测
Validation		部署完成后按设计目标逐项核对"验收单"：达标/不达标要等施工完成

AP-on-a-stick（杆上 AP）：施工前把 AP 绑在杆子上临时架到设计位置，人扛着杆验证覆盖——预测与被动/主动勘测的混搭，专业勘测的标准动作。

② 两只仪表：频谱仪 vs 协议仪

频谱分析仪 (Spectrum Analyzer) — 看"物理世界" 频谱瀑布图: 每个频率上的能量 专抓非 Wi-Fi 干扰: 微波炉(2.4G 宽脉冲)/蓝牙(跳频毛刺)/无线鼠标/坏镇流器 问题形态: "SNR 差但邻居不多" → 上频谱仪 协议分析仪 (Protocol Analyzer) — 看"协议世界" 抓 802.11 帧 (主课 20 的 monitor(监听)+Wireshark(网络协议分析器) 就是桌面版) 看帧级事实: 重传率/管理帧时序/漫游过程/保护机制开销 问题形态: "信号好但就是卡" → 上协议仪数帧 口诀: Layer 1(物理层)用频谱仪, Layer 2(链路层)用协议仪 —— 拉流排查两把都要会(企课 8)

③ 你的迷你验证流程（不买专业工具版）

目标: 评估"这环境能不能稳定拉流" (按企课 5 目标线验收) ① 环境: iw dev wlan0 scan → 邻居 AP/信道占用清单 (2.4G 半重叠?) ② 走场: iw dev wlan0 link + station dump 在"常卡的位置"采点: signal / tx bitrate / retries 三要素 ③ 空口: monitor 抓 60s, Wireshark 过滤 wlan.fc.retry==1 占比 (>15% = 空口竞争/干扰红牌) CU(信道利用率)代理指标: beacon 间隔抖动/重传统计 ④ 吞吐: iperf3 打点 (走场前后各一次, 看波动幅度) ⑤ 判定: 对照企课5表: signal>-70dBm? SNR>=25dB? retry<15%? 任何一项持续超标 → 环境问题, 不是设备问题 整套动作 30 分钟, 这就是"迷你验证勘测"

④ 专业勘测的产出（见到要认识）

  • 覆盖热图（heatmap）：信号/SNR 按位置的着色地图（红绿黄）。
  • 信道规划图：每个 AP 的信道/功率/安装位置表。
  • 干扰清单：非 Wi-Fi 干扰源位置与频段占用。
  • 验证报告：设计目标逐项打勾（−67dBm 达标区域百分比、漫游测试轨迹）。

对驱动工程师：勘测思维的两个迁移

对驱动重要 / For Driver Stack
  • 整机预认证就是"设备级勘测"：OTA（空口）测试（TRP（总辐射功率）/TIS（总各向灵敏度），企课 2）在不同方向的走场 = 你的产品在"天线维度"的验证勘测。
  • 复现客户的"环境问题"：客户现场卡顿 → 拉回实验室复现不了？用本课的迷你验证在客户现场采集三件套（scan/station dump/抓包）——环境证据带得回来，问题才修得了。这正是主课 20"报 bug 三件套"的企业版。

这课的钉子：先访谈、四勘测、两只表

  1. 先访谈定标准：用户/应用/漫游需求 → 决定测什么和目标线（企课 5 那张表）
  2. 四勘测：预测（建模）→ 被动（听覆盖）→ 主动（连性能）→ 验证（对目标）；AP-on-a-stick（杆上 AP）是施工前桥梁
  3. 两只表：Layer 1（物理层）频谱仪找非 Wi-Fi 干扰，Layer 2（链路层）协议仪看帧级事实——拉流排查两把都要
  4. 迷你验证 30 分钟：scan 环境清单 → 走场三要素 → 抓包数重传 → iperf3（网络测速工具）打点 → 对照目标线判定
  5. 产出：热图/信道规划/干扰清单/验收报告——见到要认识

你现在能做的：对自己的常卡位置做一次迷你验证；把结论写成"三件套 + 判定"格式——企课 8 的排查手册直接用得上。
