天线与传播 —— 信号为什么会"呼吸"

主课第 3/4 课把链路预算算清楚了（发射功率 − 路径损耗 + 增益 = 接收信号，RF 数学速查表可查）。但那套公式假设了一个干净的理想世界——真实世界里，人走过去信号掉 10dB（分贝）、笔记本转个方向速率掉一档、楼上楼下判若两个网络。这课补上缺的两块：电波在环境里的传播行为，和天线的形状学。这是你排查"拉流信号忽好忽坏"的物理基础。

支点：信号不是一条线，是一团会变形的"能量云"

本课支点 / Core Insight

三件套决定你收到的信号：天线决定能量云的形状（辐射方向图——往哪聚、往哪空）、环境决定能量云怎么变形（反射/散射/吸收——多径与衰落）、收发两端的天线系统决定最终 SNR（信噪比）（极化匹配、馈线损耗、驻波）。

所以"信号差"从来不是一个原因，是形状 × 环境 × 硬件链三者的乘积——排查时三样都要过一遍。

① 传播六行为：多径从哪来

行为发生条件典型场景
反射 Reflection波遇到远大于波长的平滑物体金属柜、天花板、玻璃幕墙
散射 Scattering波遇到表面粗糙或大量小物体货架、树叶、粗糙墙面
衍射 Diffraction波绕过障碍物边缘"拐弯"走廊拐角、柱子后侧还有信号的原因
折射 Refraction穿过不同介质时弯曲大气层户外链路（室内影响小）
吸收 Absorption能量被介质吃掉人体（含 70% 水）、混凝土、鱼缸——2.4/5GHz 都疼
自由空间损耗 FSPL球面波随距离扩散主课第 3 课的公式就是这个

室内主导的是反射 + 散射 → 多径：你收到的不是一列波，是 N 列走了不同长度路径、带着不同相位（和强度）的副本叠加。后果：

副 本 1: 直达, 走 4.0m ─┐ 副 本 2: 墙反射, 走 7.5m ─┼─→ 叠加: 同相 = 增强 / 反相 = 相消(衰落) 副 本 3: 天花板, 走 6.0m ─┘ 频率选择性衰落: 不同子载波频率上相消程度不同 → 某些位置/频率成"死点"(null) —— 波长十几厘米, 人挪半步就出死点! → 这就是"人走过去拉流就卡"的第一机理 (第二机理: 人体直接吸收) 两面性: OFDM 用 GI(保护间隔)吸收多径时延差 (主课 2) MIMO(多入多出) 靠多径的独立性并行传流 (主课 13) —— 多径不是纯反派: 没有 MIMO 就没有现代 Wi-Fi 的吞吐

② 天线是形状器：增益的真相

天线不放大能量（无源器件），增益 = 把能量从别处挪到你想要的方向。描述形状用两张图：方位图（azimuth，俯视水平面）和俯仰图（elevation，侧视垂直面）；形状的关键数字是波束宽度（beamwidth，功率降 3dB（分贝）处的张角）。

全向天线 (omni): 水平 360° 均匀, 垂直像 甜甜圈 高增益全向 = 把甜甜圈压扁 → 同层更远, 但楼上楼下覆盖变差! (AP(接入点) 装天花板正下方, 手机却常在楼下? 压扁的代价) 定向天线: 八木(yagi)/贴片(patch)/抛物面(parabolic) 能量集中一个锥角 → 同功率打更远, 用于桥接/点对点 增益标尺: dBi = dBd + 2.15 dBi: 相对各向同性点源(现实中不存在) ← 广告爱用, 数字大 dBd: 相对半波偶极子(真实基准天线) 7 dBi ≈ 4.85 dBd —— 比较天线先看基准!

极化（polarization）：电场的指向（垂直/水平/圆极化）。收发极化一致才高效；正交极化理论损耗可接近 20dB——手机天线极化随握持方向变化，室内因反射混合了极化而缓解，但"换个姿势信号变"是真实存在的。天线分集（diversity）：两根天线选信号好的那根（主课 13 讲过它是 MIMO 的前身）。

③ 视距与菲涅尔区：挡住的不只是"那根线"

工程直觉说"看得见就通"（LOS，视距），但严格说：电波传播需要的是一条纺锤形的净空管道——第一菲涅尔区（Fresnel zone）。经验法则：至少 60% 的第一菲涅尔区半径内无障碍（理想 80%），否则引入额外损耗。半径公式（d₁/d₂ 为障碍点到两端距离 km，f 频率 GHz，D 总距 km，结果米）：

r = 17.32 × √( d₁·d₂ / (f·D) ) 中点处最大: d₁=d₂=D/2 → r = 8.66×√(D/f) 例: 5GHz, 100m 楼间链路, 中点: r = 8.66×√(0.1/5) ≈ 1.22m → 障碍物离视线中心线 0.73m (60%) 以内就有影响! 例: 2.4GHz 同链路: r ≈ 1.77m → 频率越低, 管道越粗, "绕"性越好 长距离户外还要叠加地球曲率隆起(>10km 显著)——企课 6 勘测再算

室内场景的启示：墙不只"挡视线"，它侵入菲涅尔区；人体在 60GHz（企课 3 的 11ad）几乎完全遮挡，在 5GHz 造成明显吸收+散射——这是毫米波必须波束赋形跟踪的原因之一。

④ 硬件链：从天线口到收发机的每一分贝

  • VSWR（电压驻波比）：天线与馈线/电路的阻抗匹配度。1:1 完美，工程上 <1.5:1 算好；失配 = 功率反射回发射机（表现为"发得出去少、反射烧机"）。
  • 馈线损耗（feed line loss）：同轴线每米损耗，频率越高越大（5GHz 明显高于 2.4GHz）——外置天线拉长线时先查这张表。
  • 连接器与转接：每对连接器零点几 dB（分贝）——嵌入式设备的 IPEX/u.FL 转接线松动、天线匹配网络失谐，是"整机信号差"最常见的硬件 bug（软件栈一切正常、信号就是差 8dB 这种案子的头号嫌疑人）。
  • 法规侧：EIRP（等效全向辐射功率）上限按"发射功率 + 天线增益"算（主课 3）——换高增益天线在部分法规域要相应降发射功率。

对驱动工程师：把天线知识接进你的工具链

对驱动重要 / For Driver Stack
  • 读每根天线的信号：iw dev wlan0 station dump 里多天线芯片可看到 per-chain 信号（chain_signal，各天线链 RSSI（接收信号强度指示））——两根链差很多 = 一根天线/馈线有问题，而不是"环境差"。
  • 整机射频验收：认证/量产测试用 OTA（空口）指标：TRP（总辐射功率）/TIS（总各向同性灵敏度）——驱动/固件工程师常被拉去解释"OTA 不过"的问题，方向图知识是你的语言。
  • 信号波动的排查分叉：signal 稳定地差 → 链路预算/天线硬件；signal 剧烈波动 → 多径死点/人体吸收/干扰——两种"信号差"的处理方向完全不同。

这课的钉子：形状 × 环境 × 硬件链

  1. 传播六行为：反射/散射 → 多径 → 频率选择性衰落与死点；吸收（人体）是"人走过去就卡"的第二机理；FSPL（自由空间路径损耗）只是干净环境的底线
  2. 天线是形状器：增益=能量重分配；高增益全向压扁垂直覆盖；dBi = dBd + 2.15；极化失配最高 ~20dB（分贝）
  3. 菲涅尔区 60% 净空：r = 17.32√(d₁d₂/(f·D))；"没挡视线"≠没损耗
  4. 硬件链：VSWR（电压驻波比）/馈线/IPEX（同轴微型连接器）松动——"信号稳定地差"先查这条链
  5. 排查分叉：稳定地差 → 硬件/链路预算；剧烈波动 → 环境（多径/吸收/干扰）

你现在能做的：用 station dump 的 chain_signal 对比多天线链；把家里/公司"卡顿位置"和反射物/死点对上号；算一次自家楼间链路的菲涅尔区。
