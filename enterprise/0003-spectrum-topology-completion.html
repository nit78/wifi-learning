频谱与拓扑补完 —— 冷门 PHY 与 mesh

主课把 2.4/5/6GHz 和 BSS（基本服务集）拓扑讲透了，这课补家谱的三个非主流支线（往低频走的 11ah HaLow、往毫米波走的 11ad/ay、历史 PHY 的 DSSS/CCK）和三种非标准 BSS 拓扑（WDS/mesh/中继）。对你有三重意义：11ah 和你的 sub-GHz（亚吉赫）协议栈背景直接对口；11b 兼容模式是今天真实网络里的"慢性病"；mesh 是很多"扩展器"产品箱里的真身。

支点：一切频谱取舍都是同一条斜线

本课支点 / Core Insight

Wi-Fi 的频谱版图从 0.9GHz 到 60GHz，全部落在同一条斜线上：频率越高 → 可用带宽越大（速率越高）→ 传播越差（距离/穿墙越弱）。sub-1GHz 用 1MHz 窄信道换公里级距离，60GHz 用 2.16GHz 宽信道换十几 Gbps 但只走一个房间。没有"更好的频段"，只有"更合适的场景"——这句话是选型和排障的罗盘。

① 历史 PHY：FHSS → DSSS/CCK（为什么还要懂）

1997 原始 802.11: 2.4GHz, 2Mbps ├─ FHSS(跳频扩频): 79×1MHz 信道跳着用 ← 蓝牙的近亲, 主课 1 讲过 AFH └─ DSSS(直接序列扩频): 11-bit 巴克码扩频, 22MHz 宽信道 1Mbps(DBPSK 差分二进制相移键控) / 2Mbps 1999 802.11b (HR-DSSS, 高速直接序列扩频): CCK(补码键控): 5.5 / 11 Mbps ← 22MHz 信道形状从此固定 今天为什么还在意: ① 兼容模式最低速率: Beacon(信标帧)/组播/RTS 常用 1 或 6Mbps 发 → 一个 11b 设备入网, 全网降速保护 (主课 14 保护机制) ② 22MHz 的 2.4GHz 信道重叠格局: 1/6/11 三兄弟的由来 ③ 老厂区/老仓库的 11b-only 传感设备仍然活着

② 三个非主流频段支线

支线频段/信道能力场景 & 你该记的
802.11ah
HaLow		 sub-1GHz：美 902–928MHz（兆赫）、欧 863–868MHz 等；信道 1/2/4/8/16MHz 距离 1km 级、穿墙强；16MHz 下峰值约 347Mbps；1MHz 模式链路预算比 2.4GHz 好约 8.5dB（分贝） IoT（物联网）传感器回传。对标 LoRa 类场景但原生 TCP/IP（传输控制协议/互联网协议）全栈 + 完整 WPA2/WPA3 安全；TWT（目标唤醒时间）就是从 11ah 起家的（主课 8/15）。你的 sub-GHz 背景可直接平移理解。
802.11ad
DMG		 60GHz；6 个不重叠 2.16GHz（吉赫）信道，无绑定 单链数 Gbps~7Gbps 量级 无线投屏/扩展坞。60GHz 氧气吸收强、人几乎全挡——波束赋形是必需品而非增值项（企课 2 菲涅尔区的极端版）。
802.11ay
EDMG		 同 60GHz；信道绑定至 4.32/6.48/8.64GHz 20–100Gbps 量级 VR（虚拟现实）/8K 回传/短距点对点。ad 的四倍带宽版。
802.11af TV 空白频 54–790MHz 距离超长、速率低 地理数据库授权的"白空间"Wi-Fi——知道存在即可。

一眼记住四支线的定位：ah 换距离，ad/ay 拉流换峰值，af 蹭电视频段，主线 a/b/g/n/ac/ax 在中间过日子。

③ 拓扑补完：BSS 之外的三种活法

WDS(无线分布式系统) — AP(接入点)间桥接 四地址帧 (主课 6: DA/SA/RA/TA) 同时装下"源目 + 两跳 AP" 用途: 两栋楼点对点; 缺点: 每跳吞吐近半 + 厂商间互通不保证 802.11s Mesh(网状网) — 标准化的多跳 mesh peering(对等连接): 节点间建立对等关系 (类似关联) HWMP(混合无线网状协议): 基于 MAC(媒体访问控制)地址的路由, 按需发现路径 mesh gate: 网关节点接有线 物理规律不变: 同一射频收发分时, 每跳仍近半损耗 中继器/repeater — 信号放大转发 便宜但两伤: 吞吐减半 + 噪声也被放大转发 (干扰放大器) MBSSID(多基本服务集标识) — 一个射频装多个"虚拟 AP" 多个 SSID(服务集标识)共享一份 Beacon 时间 → Beacon 分时轮发 实战坑: SSID 开太多 → 扫描变慢 + 省电设备唤醒更频繁

对驱动工程师：mesh 在代码里的落点

对驱动重要 / For Driver Stack
  • mac80211 原生实现了 802.11s：net/mac80211/mesh.c（对等连接管理）、mesh_hwmp.c（路由）、mesh_plink.c——内核态 mesh 是现成的，做 mesh 产品多是配置+调优而非重写。
  • FullMAC（全硬件媒体访问控制）芯片：mesh 常在固件里私有实现（厂商拓扑协议），host 只见"多了一个虚拟接口"——排查 mesh 问题先分清 mesh 在哪层实现。
  • 四地址帧的驱动侧：WDS/4addr 模式在 mac80211 是一种接口类型（4addr flag），混用 3addr/4addr 帧是 WDS 掉包的经典原因（帧格式回主课 6）。
  • HaLow 芯片：多为 SDIO（安全数字输入输出）/SPI（串行外设接口）接口 + 精简 MAC 固件——你的 sub-GHz 驱动经验 + 本课程 Wi-Fi 栈知识，正好覆盖这类芯片的移植工作。

这课的钉子：一条斜线 + 三种拓扑

  1. 斜线法则：频率↑ = 带宽↑ + 距离↓——ah（sub-1GHz 换距离）/主线/ad·ay（60GHz 换峰值）全部落在这条线上
  2. 历史 PHY：FHSS（跳频扩频）→DSSS（直接序列扩频）/CCK（补码键控）→11b 定型 22MHz 信道；兼容模式拖累全网（保护机制+低速信标）
  3. HaLow（11ah）：sub-1GHz + 1/2/4/8/16MHz（兆赫）信道，原生 TCP/IP（传输控制协议/互联网协议）全栈，TWT（目标唤醒时间）老家——sub-GHz 工程师的对口领地
  4. 60GHz（ad/ay）：2.16GHz 宽信道可绑至 8.64GHz；波束赋形是生死线不是可选项
  5. 拓扑三件：WDS（无线分布式系统）四地址桥接、802.11s mesh（mac80211 原生支持）、中继器放大噪声；MBSSID（多基本服务集标识）开太多拖累扫描与省电

你现在能做的：把家里/公司的"信号扩展器"判断出真身（WDS/mesh/中继）；给 sub-GHz 项目对比一次 HaLow 方案；看到 11b 设备入网速率下降时说出保护机制。
