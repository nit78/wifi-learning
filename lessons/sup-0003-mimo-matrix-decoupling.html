MIMO 矩阵解耦 —— 为什么两流不互相干扰

这是第 13 课 MIMO 基础的数学深入。核心问题：两个空间流用同一频段同一时间发，接收端怎么把它们分开？ 直觉上它们应该互相干扰——但 MIMO（多入多出）用一个数学技巧把它们解耦成独立通道。搞懂这个，MIMO 就不再是黑盒。

前置：你需要记得的

矩阵乘法、矩阵转置（Aᵀ）、共轭转置（Aᴴ，转置+取复共轭）、对角矩阵。不需要会算 SVD，只要理解它"做了什么"。

① 信道模型：两流确实"混"了

2×2 MIMO（2 发 2 收）的物理模型。发端发两个符号 x₁、x₂，收端两根天线收到的是它们的线性混合：

收端天线 1 收到: y₁ = h₁₁·x₁ + h₁₂·x₂ + n₁ 收端天线 2 收到: y₂ = h₂₁·x₁ + h₂₂·x₂ + n₂ 写成矩阵: [y₁] [h₁₁ h₁₂] [x₁] [n₁] [y₂] = [h₂₁ h₂₂]·[x₂] + [n₂] y = H · x + n h_ij = 从发天线 j 到收天线 i 的信道系数（复数：幅度+相位） n = 噪声。关键是: 收到的是 x₁、x₂ 的【混合】, 不是分离的

问题来了：y 里 x₁ 和 x₂ 搅在一起，怎么分开？ 如果 H 已知（接收端能测出来），这其实是个解线性方程组——但有 4 个未知量耦合，且每时刻 H 都在变。MIMO 用 SVD（奇异值分解）把它变成独立的标量方程。

② SVD：把耦合矩阵拆成正交模式

奇异值分解 (Singular Value Decomposition, SVD) 是线性代数的神器：任何矩阵 H 都能分解成三个特殊矩阵的乘积：

H = U · Σ · Vᴴ 其中: U: 收端酉矩阵（列向量正交），N×N，N=收天线数 Σ: 对角矩阵，对角元素 σ₁,σ₂... ≥ 0，奇异值，代表各"空间模式"的增益 Vᴴ: 发端酉矩阵的共轭转置（V 的列正交），M×M，M=发天线数

关键直觉：SVD 把"搅在一起的 MIMO 信道"拆成若干个独立的空间模式（spatial mode），每个模式有自己的增益 σᵢ。模式之间正交——不互相干扰。模式数 = min(收天线, 发天线) = 空间流数的上限。这就是为什么第 13 课说"空间流 ≤ min(收发天线数)"。

③ 魔法：用 V 和 U 把混合变独立

把 H = UΣVᴴ 代回 y = Hx + n：

y = U·Σ·Vᴴ·x + n 关键操作： 1. 发端预编码 (precoding)：实际不直接发 x，而是发 V·x' 发的信号 = V·x'，让 V 和信道里的 Vᴴ 抵消 2. 信道传输后: y = U·Σ·Vᴴ·(V·x') + n = U·Σ·x' + n (因为 Vᴴ·V = I，酉矩阵性质) 3. 收端后编码 (postcoding)：收端用 Uᴴ 乘 y Uᴴ·y = Uᴴ·U·Σ·x' + Uᴴ·n = Σ·x' + Uᴴ·n (因为 Uᴴ·U = I) 最终: Uᴴ·y = Σ·x' + 噪声 Σ 是对角矩阵! 这就是 N 个【独立的标量方程】: (Uᴴ·y)₁ = σ₁ · x'₁ + ñ₁ (Uᴴ·y)₂ = σ₂ · x'₂ + ñ₂
这就是 MIMO（多入多出）的核心魔法：通过发端预编码（用 V）+ 收端后编码（用 Uᴴ），把原本耦合的 MIMO 信道解耦成 N 个独立的标量子信道。每个子信道就是一个简单的"幅度缩放 σᵢ"——和单天线通信一模一样，只是增益是奇异值 σᵢ。

每个空间流就是一个子信道：流 i 走子信道 i，增益是 σᵢ。σᵢ 大的子信道信号强（能传高阶调制），σᵢ 小的信号弱（只能传低阶或不传）。这就是"注水定理 (water-filling)"的来源——把功率多分给 σ 大的子信道，总吞吐最大化。

④ 波束成形 = 预编码的特例

回看第 13 课的"波束成形"——加权对齐信号。现在有数学语言了：

波束成形 = 发端用 V 预编码 发端知道 V（从 sounding 拿到 CSI 算出来）→ 按 V 加权发射 → 信号在收端 Uᴴ 后编码后相干叠加增强 这也是为什么波束成形需要 CSI（信道状态信息）： V 来自 H 的 SVD，H 来自 CSI 没 CSI → 没 H → 没 V → 没法预编码 → 没波束成形

第 13 课讲的"sounding（信道探测）拿 CSI（信道状态信息）"，拿到的 CSI 就是用来构造 H 并算出 V/U 的。所以波束成形不是独立的"魔法"，而是 SVD 框架里发端预编码的实现。

⑤ 单流情况：退化成 MISO 波束成形

当只发一个流（x' 是标量），SVD 框架退化：

单流: x' 是 1×1 标量, 只用最大奇异值 σ₁ 对应的模式 V 退化成列向量 v₁（发端波束成形权重） U 退化成列向量 u₁（收端合并权重） 发端: 多天线按 v₁ 加权 → 在收端方向相干增强 收端: 按 u₁ 加权合并 → 最大化 SNR 这就是第 13 课的"波束成形"和"MRC（最大比合并）"的数学本质

对驱动栈：这些数学你能看到吗

对驱动重要 / For Driver Stack

诚实说：这套 SVD 数学几乎全在硬件/基带 DSP 里，驱动工程师看不到代码。但你该懂的是：

  • "空间流数"和"奇异值个数"对应——所以流数受 min(收发天线) 限制。你看到芯片 spec 写"支持 2 流"，背后是 SVD 能解出 2 个有效模式。
  • rate adaptation（速率自适应）的输入是奇异值——σ 大的子信道走高 MCS（调制与编码方案），σ 小的走低 MCS。minstrel_ht 间接在调这个。
  • 波束成形失败 = V 算不对——CSI 测量不准 / 过期 → SVD 出错 → 预编码把信号"对错方向" → SNR（信噪比）反而下降。抓包看到的是"波束成形激活但吞吐没提升"。
  • 为什么 802.11ac 只用显式反馈：显式反馈直接给 V（压缩矩阵），准；隐式靠互易性推 H 算 V，RF（射频）不一致导致 V 算偏——这就是校准麻烦的根源。

你做驱动时，这套数学是"为什么"的背景，不是"怎么做"的代码。但懂了这个，调试波束成形/空间流问题时你能判断"是不是 CSI/sounding 出问题"。

一句话总结

MIMO 不是"多根天线发不同数据"这么简单——发出去的信号确实混合了。但通过 SVD 把信道矩阵 H 拆成正交模式，发端预编码（V）+ 收端后编码（Uᴴ）把混合解耦成 N 个独立标量子信道。每个子信道就是一个空间流，增益是奇异值 σᵢ。

波束成形是单流时的特例（只用最强模式），需要 CSI 来算 V。这套数学是 MIMO 一切特性的根——空间复用、波束成形、MU-MIMO（多用户 MIMO，下节课）都建立在它上面。
